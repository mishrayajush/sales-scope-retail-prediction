BEHIND THE ESTIMATE

Historical patterns.
One day at a time.

SalesScope uses a machine learning model to estimate a store’s daily sales from calendar patterns, store information, and planned promotions.

What should I know about these predictions?

The model learned from data through {{ training_end|default('June 2015') }}. It was evaluated on the following six weeks. Later dates are available as demonstrations, but recent data is needed to assess current forecasting performance.

Sales are in the original dataset’s units. Promotion associations do not establish causal effects. A store number identifies an existing dataset branch, not a new store you can add.
