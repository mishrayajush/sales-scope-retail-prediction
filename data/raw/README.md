# Rossmann source data

Source: https://www.kaggle.com/c/rossmann-store-sales/data

Sign in, accept the competition rules, download and extract `train.csv` and
`store.csv` into this directory. Keep the original CSVs unchanged. Do not use
the competition `test.csv` for scoring because it does not contain sales labels.
The project creates its own chronological validation and test sets from train.csv.
Respect the competition's rules when sharing data or derived artifacts.

No real dataset is bundled. Synthetic test fixtures are software checks only.
